# Safety MVP
- العمر بين 2 و16.
- مفتاح OpenRouter يبقى في الخادم ولا يدخل APK.
- منع طلب العنوان والهاتف والمدرسة وكلمات المرور والموقع الدقيق.
- حجب مبدئي للمواضيع الجنسية وإيذاء النفس والأسلحة/المتفجرات والمخدرات.
- الردود غير الآمنة تُستبدل برسالة آمنة.
- قبل الإنتاج: authentication، rate limiting، اختبارات سلامة واسعة، سياسة خصوصية ومراجعة قانونية مناسبة للأطفال.
